4. Daemon image check karta hai
5. Missing image Docker Hub se download hoti hai
6. Container create hota hai
7. Application run hoti hai

So we need to take care of PORT Mapping

Port Mapping -
Port Mapping ka use:
	container ke andar chal rahi application ko
	outside/browser se access karne ke liye hota hai

docker run -it -p 8000:5000    .. aka local-port : container-port

https://localhost:8000  >> -- Output -- { "message":"hello from docker 26" }

docker run -it -e PORT=7000 -p 8000:7000 test-image   
.. aka -e denotes environment variable

!!!!! Port Mapping - !!!!!
Syntax 
Bash
docker run -p host_port:container_port image_name
Bash 
docker run -p 8000:5000 my app


!!!!! Add Environment Variable in run time - !!!!!
Bash
docker run -e PORT=8000 -p 8000:8000 myapp
